Classfile Format Sizes (Architecture-Independent)

These sizes are defined by the JVM specification and are the same on all architectures.

TypeBytesSlots in Constant PoolExample
byte11byte b = 42;
char21char c = 'A';
short21short s = 100;
int41int i = 1;
float41float f = 1.0f;
long82long l = 1L;
double82double d = 1.0;
boolean1 (in classfile)1boolean b = true;
reference4 (32-bit) or 8 (64-bit)1Object obj = ...;

Why Reference Size Varies

  • On 32-bit: 4-byte addresses → 4-byte references (max heap ~2GB)
  • On 64-bit: 8-byte addresses → 8-byte references (max heap ~16EB)
  • With compressed oops: 64-bit JVM can use 4-byte references if heap < 32GB
